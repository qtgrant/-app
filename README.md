# 个人记录 App · 人生周历

在线使用：https://life-weeks-qtgrant.kind-flea-4473.chatgpt.site/

## 功能

- 90 年人生周历，每年 48 格，保留方格比例和侧栏布局。
- 输入年龄自动标记已度过的年份，已有特别标记、计划和备注保留。
- 手动标记、周记、生日日期区间、JSON 备份导入导出。
- 自动迁移旧的每年 52 格记录。

## 使用

下载并用浏览器打开 `index.html`，无需安装依赖或构建。也可将此文件部署到静态网页托管服务。

记录保存在当前浏览器的 localStorage，不会自动跨设备同步。不同网址或本地文件的记录互不共享，迁移时请先导出备份，再在新地址导入。

当前在线版本由 Sites 托管；GitHub 仓库保存应用源文件，提交到本仓库不会自动更新 Sites。
